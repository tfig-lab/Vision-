Interações por grupo e Razao

Grupo = coluna L (Consolidação Operação) da planilha de-para, ligada pelo código do evento. Use o botão Grupo / Razao em cada quadro. "Perda" é o tempo equivalente perdido em relação à referência. Exemplo: 60 s a 50% da referência = 30 s perdidos. Quando há mais de uma interação ativa ao mesmo tempo, a perda da leitura é dividida em partes iguais entre elas.

Carregar novos dados

Escolha os arquivos no mesmo formato dos que usamos aqui, e o painel inteiro é refeito com eles. Para vários dias, selecione (ou arraste) vários arquivos de interações e vários de velocidade de uma vez; registros repetidos entre arquivos são descartados. O processamento roda no seu navegador: os arquivos não são enviados para lugar nenhum e não ficam salvos. Ao recarregar a página, o painel volta para os dados originais.
